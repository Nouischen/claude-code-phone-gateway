# Notes for AI agents working in this repo

This repo makes a Windows PC reachable from the Claude mobile app so the phone can start
**local** Claude Code sessions here. Read `README.md` first; it is the source of truth.

## If the user asked you to install it

Run these, in this order, from the repo folder, and show the user the output of each:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\doctor.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Name "<a name the user likes>"
```

- If `doctor.ps1` prints any `FAIL`, stop and relay the fix line verbatim. Do not work around it.
- `install.ps1` refuses to install when the live probe fails. That is intended; do not pass `-SkipProbe`
  to get past it.
- Success looks like a `connected: https://claude.ai/code?environment=...` line in
  `<WorkDir>\logs\gateway.log` and `[4/4] gateway running and connected` from the installer.
- Then tell the user the phone-side steps from README ("Use it from your phone").

## Rules

- Never use the user's profile root as `-WorkDir`; Claude refuses to serve it. Default is this folder.
- Do not edit `~/.claude.json` by hand. `install.ps1` adds exactly one trust entry and backs the file up first.
- Do not create scheduled tasks, services, or registry entries. The only persistence is the Startup shortcut.
- Do not start a second gateway for the same folder; `gateway.lock` will refuse anyway.
- To remove everything the installer added: `.\install.ps1 -Uninstall`.
- Keep the scripts pure Windows PowerShell 5.1 and ASCII only. No modules, no Python, no Node.

## Files

| File | Role |
| --- | --- |
| `gateway.ps1` | The supervisor. `-Test` starts the server once, prints the environment URL, exits |
| `doctor.ps1` | Environment checks plus the live probe |
| `install.ps1` | Trust, probe, Startup shortcut, start. `-Uninstall` reverses it |
| `link-memory.ps1` | Optional: junction so phone sessions share another project's memory |
| `lib.ps1` | Shared helpers, dot-sourced by the others |
| `run-hidden.vbs` | Launches a command with no window; used by the Startup shortcut |
| `start-gateway.cmd` | Generated by the installer; the exact command line the Startup entry runs |

Runtime files (`logs\`, `gateway.lock`, `ALERT-gateway.txt`, `start-gateway.cmd`) are git-ignored.
